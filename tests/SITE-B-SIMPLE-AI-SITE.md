# Site B — Simple AI-built website: controlled baseline

**Status:** Baseline frozen at commit `61950bab3dc13c6b6e1093c7a84296853b05032d`; isolated makeover and local evidence completed 2026-10-24.
**Fictional business:** Cedar & Stone Home Services (handyman landing page)
**Purpose:** Demonstrate improvement on a buyer-like, small, generic AI-built site, without using real personal data or fake business credibility claims.

## Neutral generation prompt

> Create a modern, professional one-page website for Cedar & Stone Home Services, a **fictional** local handyman business. Include a hero section, three service cards (minor home repairs, seasonal maintenance, assembly), an About section, and a contact section. Use placeholder contact information. If you include testimonials, mark them clearly as fictional example content. Make the page responsive. No backend, no external paid services, and no real booking integrations.

## Baseline requirements

- Generate the site once, without deliberately sabotaging its design.
- Freeze source and capture desktop/mobile screenshots **before** any Rescue prompt.
- Do not regenerate a different baseline for control and test.
- Use the same AI model/context materials in fresh sessions for Control and Rescue.
- Do not publish a fake business site with live deceptive reviews or contact details.

## Required evidence

- AI builder name/model and generation date
- Exact baseline generation prompt
- Source commit or export reference
- Screenshots at 390px, 768px, and 1440px
- Navigation/form behavior notes (a nonfunctional placeholder contact section must remain clearly identified)
- Independent control and Rescue audits, scores and corrections
- Verified before/after images with matching viewports

## Rescue test sequence

1. Run Bonus 01 against the unmodified baseline.
2. Run Prompt 02 for template/genericity and Prompt 07 for hero alternatives.
3. Select approved changes and use Prompt 11 only if source/edit access is available.
4. Run Prompt 12 to evaluate evidence and regression status.

Do not call the example an actual before-and-after until both versions and review evidence exist.

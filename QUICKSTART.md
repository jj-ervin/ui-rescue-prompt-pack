# AI UI Rescue Kit — Quick Start (Draft)

This is a copy-and-paste prompt toolkit, not a website redesign service.

## Choose a path

1. **Fast:** use Bonus 01 for an initial makeover plan.
2. **Targeted:** pick a prompt focused on one issue (typography, spacing, color, hero, mobile, accessibility, etc.).
3. **Complete:** start with core Prompt 01, then select applicable audit and improvement prompts; use Prompt 11 only for approved implementation and Prompt 12 for verification.
4. **Recovery:** if an AI redesign changed or broke something, use Bonus 03.

## Before using any implementation prompt

- Make a backup or commit a known-good state.
- Provide the AI with the URL, screenshots, or project files it can actually access.
- Specify the audience and primary website goal.
- Review the suggested changes and approve scope before implementation.
- Do not provide production credentials, sensitive customer data, or unrestricted production access.
- Verify navigation, forms, keyboard use, mobile layout, contrast, and content after changes.

An AI assistant should report what it can observe and what remains unverified. Prompts alone do not ensure no regressions or WCAG compliance.

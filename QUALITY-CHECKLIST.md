# Website Rescue — Final Quality Checklist

For any implementation, record **Pass / Fail / Not Tested** and link evidence when possible.

- [ ] Purpose and intended action are clear to a new visitor
- [ ] Heading order and content hierarchy make sense
- [ ] Body typography is readable at intended widths and increased zoom
- [ ] Spacing and alignment are coherent
- [ ] Text and meaningful UI color contrast have been evaluated
- [ ] Recurring buttons, cards, forms and states are consistent
- [ ] Navigation, links, buttons and forms work as before
- [ ] Mobile layout has no unintended horizontal scrolling
- [ ] Mobile menus and touch targets remain usable
- [ ] Keyboard focus is visible and tab order is usable
- [ ] Relevant accessibility failures have been recorded and addressed or disclosed
- [ ] Content, routes, integrations and functionality remain intact
- [ ] No unapproved framework or dependency changes occurred
- [ ] Before/after screenshots use equivalent browsers, viewports, content and states
- [ ] Tests actually run and their results are documented
- [ ] Remaining limitations and unverified claims are clearly reported

A checklist alone does not certify WCAG conformance or absence of regressions.

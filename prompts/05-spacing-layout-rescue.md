# 05 — Spacing & Layout Rescue

**Use when:** The page feels cramped, stretched, misaligned or visually uneven.

## Copy-paste prompt

Act as a UI layout specialist.

**Website or materials:** [INSERT]

Review section spacing, internal padding, margins, alignment, grid consistency, content widths, card dimensions, vertical rhythm and responsive composition.

Identify exact inconsistencies and unclear visual relationships, including whether they are truly defects or intentional grouping. Recommend a compact reusable spacing scale and sensible content/container widths rather than arbitrary one-off values.

Output a table with location, observation, impact, recommended fix, proposed token or measurement (if evidence permits), responsive implications, and how to verify. Identify the **three highest-value fixes** first.

Respect current framework and semantic content order. Do not propose unnecessary wrappers, CSS rewrites or new layout dependencies. **Do not edit before approval.**

## Working rules
- Examine only materials actually accessible; separate observed defects from suspected risks.
- Preserve existing functionality, routes, content meaning, brand identity and architecture unless explicitly authorized.
- Do not invent inspection, test results, evidence, testimonials, or accessibility compliance.
- If changes need code access, do not claim they were made without editing and verifying them.

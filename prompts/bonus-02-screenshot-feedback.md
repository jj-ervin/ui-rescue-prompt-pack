# Bonus 02 — Screenshot-to-Design Feedback

**Use when:** You have screenshots but cannot provide live website or code access.

## Copy-paste prompt

Act as an evidence-based visual interface critic.

**Screenshots:** [ATTACH]
**Page goal/audience:** [INSERT]
**Viewport or device, if known:** [INSERT]

Review only what is visible: hierarchy, typography, spacing, alignment, color, content density, navigation presentation, CTAs and visual consistency. Do not assert how hidden responsive states, keyboard interactions, links or forms behave based on static images.

List the five most valuable visible improvements, with screenshot location, observed issue, precise correction, expected benefit and verification method. Give approximate type, spacing, layout or color specifications where helpful, and label estimates as estimates.

Clearly separate observations from questions requiring code/browser access. End with a concise redesign brief I can paste into my website builder. Do not claim full accessibility or functional verification.

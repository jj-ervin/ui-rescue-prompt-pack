# 04 — Typography Rescue

**Use when:** Text sizes, fonts, line heights or reading widths feel inconsistent.

## Copy-paste prompt

Act as a digital typography specialist.

**Website, screenshots or code:** [INSERT]
**Existing typefaces or design tokens:** [INSERT if known]

Inspect heading hierarchy, font suitability, family/weight consistency, body readability, line height, letter spacing, paragraph width, navigation/buttons, mobile scaling and text contrast.

First list observed typography problems with locations. Then propose a **small typography system** for relevant H1–H6 levels, body, secondary text, navigation, buttons and captions. Where appropriate give example CSS values or design tokens for sizes, weights, line heights, line lengths and responsive scaling; clearly mark estimates when source styles are unavailable.

Prefer current fonts unless replacement would provide a concrete benefit. Avoid adding many font families. Specify how to verify readability at narrow viewports and enlarged text/zoom. Show one before/after *specification* example, not an invented screenshot.

**Stop before implementation.**

## Working rules
- Examine only materials actually accessible; separate observed defects from suspected risks.
- Preserve existing functionality, routes, content meaning, brand identity and architecture unless explicitly authorized.
- Do not invent inspection, test results, evidence, testimonials, or accessibility compliance.
- If changes need code access, do not claim they were made without editing and verifying them.

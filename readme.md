# AI UI Rescue Kit

A planned $9 digital prompt kit for non-developers improving AI-built websites.

## Product scope

- 12 core prompts: audit, generic-design detection, hierarchy, typography, spacing, color, hero, components, mobile, accessibility, implementation, and verification.
- 3 bonus prompts: quick rescue, screenshot feedback, and redesign recovery.
- Quick-start guidance, final checklist, and verified demonstration examples.

## Directories

- `prompts/` — editable prompt source
- `examples/` — consented before/after examples and screenshots
- `tests/` — evaluation notes and actual test results
- `release/` — customer-ready export files (only when validated)

Status: content drafted in ChatGPT; repository product content, examples, and release remain to be produced and verified.
